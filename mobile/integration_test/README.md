# Pruebas de integración

Añade aquí recorridos completos cuando las historias estén implementadas y se
acuerde un entorno de prueba. La base solo contiene una prueba de widgets en
`test/app_test.dart`.

Para incorporar recorridos, añade `integration_test` como dependencia de desarrollo
del SDK y ejecuta `flutter test integration_test` con un dispositivo disponible.
Estas pruebas no se ejecutan todavía en CI.
