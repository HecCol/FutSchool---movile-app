# Evidencias

Incorpora capturas reales de instalación, diagnóstico, ejecución y pruebas.
Registra comando o acción, fecha, dispositivo, versión y resultado observado.

Nombres: `aaaa-mm-dd-descripcion.png`; por ejemplo `2026-09-30-flutter-doctor.png`.
Ese nombre es un ejemplo, no una evidencia creada. Evita tokens, contraseñas
y datos privados. Los resultados de CI se consultan en Actions del repositorio.
