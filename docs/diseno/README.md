# Diseño de interfaces

Guarda el inventario de pantallas, decisiones de navegación, imágenes y enlace
del prototipo aprobado. Relaciona las pantallas con las Issues vigentes; el
documento inicial utiliza un backlog más pequeño.

Registra objetivo, rol, campos, acciones, navegación y estados de carga, error,
validación y listas vacías. Este directorio aún no contiene el prototipo ni
un enlace de Figma registrado.
